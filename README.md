# Log Archive Tool

A simple CLI tool to compress and archive log files on a Unix/Linux system.

## 🧠 Project Overview

This script helps to automatically compress and store logs on a schedule to keep the system clean and organized.

It takes a log directory as an argument, compresses its contents into a `.tar.gz` file, and stores it in a new `archives` directory.

---

## ⚙️ Usage

```bash
./log-archive.sh <log-directory>
